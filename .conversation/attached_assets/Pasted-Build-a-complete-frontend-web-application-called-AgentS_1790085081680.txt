Build a complete frontend web application called "AgentSOC" — an Autonomous Cloud Security Operations Center.

IMPORTANT:
This is a B.Tech final-year cybersecurity project. The application must look like a serious, technically advanced Security Operations Center (SOC), NOT a generic SaaS/admin dashboard.

The visual design should be inspired by the attached reference image:
- black background
- neon magenta/pink
- neon lime green
- futuristic typography
- thin technical borders
- subtle glow
- cyberpunk aesthetic
- grid/noise textures
- sharp rectangular panels
- technical/monospace text

However, DO NOT copy the gaming/community content of the reference. Adapt only its visual style to cybersecurity.

==================================================
1. TECHNOLOGY
==================================================

Use:

- React
- TypeScript
- Next.js
- Tailwind CSS
- shadcn/ui
- Lucide icons
- Recharts for charts

Create clean, reusable components.

Structure the project so it can later connect to a FastAPI backend.

for the backend URL.

The frontend must initially work even when the backend is unavailable by using clearly separated mock/demo data.

==================================================
2. PROJECT CONCEPT
==================================================

AgentSOC monitors a simulated AWS cloud environment and processes security events through multiple specialized AI agents.

Architecture:

AWS Cloud
    ↓
Monitor Agent
    ↓
PostgreSQL / Event Store
    ↓
Triage Agent
    ↓
Investigator Agent
    ↓
Compliance Agent
    ↓
Approval Gate
    ↓
Human Approval OR Auto Approval
    ↓
Remediation Agent
    ↓
Dashboard / Audit Log

The five main agents are:

1. Monitor Agent
2. Triage Agent
3. Investigator Agent
4. Compliance Agent
5. Remediation Agent

The frontend must visually communicate this pipeline.
